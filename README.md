# 《塞尔达传说：时之笛3D》 - 高清字体与地图材质包（简体及繁体）

此高清化补丁是《塞尔达传说：时之笛3D》的文本，UI，地图的中文（包含简体和繁体）高清化重制版，可在CItra或者Azahar模拟器开启使用。

## 高清化说明

- NPC对话，一般UI和带文字的UI
- 主地图和迷宫地图的高清化，不包含副屏地图
- 本次重制版文本是基于**原版**字体高清，新增**繁体中文**
- 针对**Citra**和**Azahar**高内部分辨率**优化**
- 提供**预制PNG资源**，直接使用，无需额外工具

## 使用说明

- 可在**Citra**或**Azahar**模拟器中使用
- 须有《塞尔达传说：时之笛3D》 - **简体或繁体中文版** ROM
- 开启自定义纹理，打开模拟器，点击 **模拟** > **设置** > **图形**，找到并勾选√ **使用自定义纹理**
- 此高清化仅支持**简体中文**和**繁体中文**

## 安装说明

1. 打开**CItra**或**Azahar**
2. 找到《塞尔达传说：时之笛3D》
3. 右击时之笛，选择打开**自定义材质位置**，或者打开模拟器根目录，依次找到user/load/textures/000400000008F900/
4. 纹理包并非直接解压就可以用，解压后有**4个**文件夹，可自行挑选需要的，在此说明一下文件夹对应的文件：
 **Chinese UI**为高清中文UI
 **MAP为**高清地图
 **TEXT**为对话文本
 **UI**为无字UI
5. 由于分为了简体和繁体，需要自行挑选，**CN**为简体，**TW**为繁体
6. 将纹理包解压，解压后文件夹不要以**中文命名**，选择自己需要的高清内容，将文件夹拖入user/load/textures/000400000008F900/
7. 务必确保已勾选√ **使用自定义纹理**，然后启动游戏即可生效

## 文件说明

所有文件都是PNG格式图片，此压缩文件不包含任何游戏ROM，须自备可正常使用的《塞尔达传说：时之笛3D》简体或繁体**中文版**ROM
